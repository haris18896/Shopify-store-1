# Asset and License Register

No third-party runtime or demo assets are currently included in the theme.

## Register rules

Add an entry before an asset is used in theme code, a demo store, marketplace screenshots, or marketing material. Keep the source file, purchase receipt/license certificate, and a copy of the license text with the project records.

Required fields:

- Asset filename and purpose
- Creator/rightsholder
- Original source URL
- Download or purchase date
- License name and version
- Commercial use allowed
- Redistribution inside a paid theme allowed
- Preview/demo use allowed
- Attribution requirement
- Proof-of-license location
- Modifications made
